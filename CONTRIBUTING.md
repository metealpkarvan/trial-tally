# Contributing to Trial Tally

Run npm test and npm run build with Node.js 22+. Serve with npm start.

Report reproducible steps, expected/actual results, browser version and nonsensitive examples. Never post private transcripts, credentials or unredacted backups.

Keep domain behavior in src/core.js and add meaningful regression tests for changed rules. Verify browser flows, both languages and a narrow mobile viewport for UI changes. Avoid packages or services unless a capability requires them.

Describe the concrete problem, resulting behavior, validation and changed privacy boundary in pull requests.
